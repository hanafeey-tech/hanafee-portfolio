# Static portfolio for Google Sites embedding

This folder contains the seven-page portfolio and only the images referenced by those pages. Resume and transcript PDFs are intentionally excluded.

## GitHub Pages publishing

1. Create a GitHub repository for this site and upload the contents of this folder to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/(root)`, then save.
4. After GitHub Pages publishes the site, copy its HTTPS URL.
5. In Google Sites, open the intended page and choose **Insert → Embed → By URL** (or **Pages → Add → Full page embed**) and paste the hosted `index.html` URL.

The portfolio links stay inside the embedded frame and navigate among the hosted HTML pages. Publish the Google Site after confirming its sharing audience.

## Privacy before publishing

GitHub Pages is publicly available on the internet. The portfolio currently displays contact details from the local page. Review or remove the phone number and email address before publishing if you do not want them public. This folder does not include the resume or transcript PDFs.
